# DolphinVR Redux updates

This repository is the update server of [DolphinVR Redux](https://github.com/iChris4/dolphinXR)
for Windows. GitHub Pages serves it at https://ichris4.github.io/dolphinxr-updates.

DolphinVR Redux's built-in updater reads the list of releases here, then downloads the files of
the new release. Every release is signed: the updater rejects anything not signed with
DolphinVR Redux's key.

There is nothing to download by hand here. To install DolphinVR Redux, use the
[releases page](https://github.com/iChris4/dolphinXR/releases).

The files are generated by `Tools/dolphinxr-update.py publish` in the DolphinVR Redux source
tree. Do not edit them by hand. The procedure is in `docs/DolphinXR-Updates.md` there.

| Path | Content |
| --- | --- |
| `update/v1/<track>/<platform>/latest.json` | The releases of a track, newest first |
| `update/v1/<platform>/manifests/<commit>` | The signed list of the files of each release |
| `update/v1/content/` | The files, gzipped and named by their hash |
